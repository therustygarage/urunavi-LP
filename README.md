# URUNAVI LP

バイク委託販売「URUNAVI」（THE RUSTY GARAGE）のランディングページです。

- 公開方法：GitHub Pages（このリポジトリの `main` ブランチ直下を公開）
- 本体：`index.html`（単体ファイル、外部画像は公式HPのものを使用）
- CTAリンク先：売却相談・申込フォーム（Googleフォーム）／公式LINE

## 更新方法

`index.html` を編集して `main` に push すると、GitHub Pages に自動で反映されます（数分かかる場合があります）。

アンカー：

- 仕組み・料金 → `/#fee`
- よくある質問 → `/#faq`
